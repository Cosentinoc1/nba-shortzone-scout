Connect a permitted independent data API or publish your existing Google Sheet as CSV. Until then, use Import CSV from your daily prop board. Live lines require the source to be configured; this site does not scrape PrizePicks.

How to connect automatic lines

In Render → nba-shotzone-scout → Environment, set PRIZEPICKS_API_KEY to a key from an independent licensed feed such as prizepicksapi.com. Or, after choosing to publish the board, set PROPS_CSV_URL to its public Google Sheets CSV URL. Never paste API keys into this page.
